# Google Sites mirror

The recommended mirror is the GitHub Pages deployment of `web/`.

## Option A — embed

In Google Sites:

1. Open the site editor.
2. Insert → Embed.
3. Select URL.
4. Paste the HTTPS GitHub Pages URL.
5. Resize the embed to the desired height.

## Option B — button

Create a button linking to the GitHub Pages URL.

The Google Sites page should be considered a presentation/mirror layer. The GitHub repository and deployed PWA remain the source of truth.

Do not place Apps Script secrets in Google Sites.
